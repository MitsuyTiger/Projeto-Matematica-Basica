# 🧮 Projeto Matemática Básica

## 🎯 Objetivo
Este projeto foi criado para ajudar pessoas a **praticarem operações matemáticas simples** — soma, subtração, multiplicação e divisão — de forma acessível e educativa.  
A ideia é tornar o aprendizado de matemática mais leve e interativo, especialmente para iniciantes.

---

## 💻 Tecnologias utilizadas
- **Python** → linguagem principal do projeto  
- **GitHub** → para versionamento e compartilhamento do código
